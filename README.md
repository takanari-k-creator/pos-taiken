# コンビニPOSシミュレーター（情報Ⅰ 情報システム）

生徒がコンビニのお客さんになって買い物をすると、その購入データが自動で集まり、
「本部になる」画面でクラス全員のデータを一緒に見られる教材です。

- 生徒の画面：`https://<ユーザー名>.github.io/<リポジトリ名>/?room=2A`
- 本部（先生）の画面：同じURLで「本部になる」タブ（`#honbu` を付けると最初から本部画面）
- `room=` の値でクラスを分けます（英数字・ハイフン・アンダーバー、20文字まで）

## しくみ

```
生徒のブラウザ ──(買い物ごとにPOST)──▶ Google Apps Script ──▶ スプレッドシート
本部の画面    ◀──(5秒ごとにGET)──────┘
```

GitHub Pages は静的なページしか置けないため、データの保存先に Google スプレッドシート（Apps Script）を使います。
送られるのは架空の購入データ（年齢層・曜日・時刻・天気・気温・支払方法・商品）と、ランダムな3文字の生徒IDだけです。氏名などは送りません。

## 準備（最初の1回だけ・10分ほど）

### 1. スプレッドシートとApps Script
1. Googleドライブで新しいスプレッドシートを作る（名前は自由）
2. メニュー「拡張機能」→「Apps Script」
3. 最初からある `コード.gs` の中身を全部消して、このリポジトリの `Code.gs` を貼り付ける
4. 1行目の `ADMIN_KEY` を好きな合言葉に変えて保存
5. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
6. 「デプロイ」→ 権限の承認 → 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピー

> 学校のGoogle Workspaceの設定で「全員」が選べない場合は、「（学校のドメイン）内の全員」を選び、生徒は学校アカウントでログインしたブラウザで使ってください。

### 2. index.html にURLを入れる
`index.html` の上の方にある

```js
const GAS_URL='';
```

の `''` の中に、コピーしたURLを入れてコミットします。

### 3. GitHub Pages を有効にする
リポジトリの Settings → Pages → Branch を `main` / `/(root)` にして Save。
数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます。

## 授業での使い方
1. 本部（先生）の画面をプロジェクターに映し、生徒にURL（`?room=クラス名` 付き）を配る
2. 生徒は3分間お客さんになって買い物（支払うたびに自動で送信。画面に「✓ 本部に届きました」）
3. 本部画面は5秒ごとに自動更新。みんなで「データベースの中身」などを見る
4. 授業後、「管理キー」を入れて「このクラスのデータを消す」で片付け（スプレッドシートを直接消してもOK）

`GAS_URL` が空のときは、生徒が「提出用コード」をClassroomなどに貼り、先生がまとめて本部画面に貼り付ける方式で動きます。
通信がうまくいかないときの予備としても使えます（自動共有モードでも本部画面の「提出用コードを貼り付けて取り込む」から使えます）。

## 注意
- ウェブアプリのURLを知っている人は誰でもデータを送れます。受け取るのは決まった形式の購入コードだけですが、授業が終わったらデータを消してください。
- Apps Script のコードを変更したときは「デプロイを管理」→ 編集 →「新しいバージョン」で再デプロイが必要です。
